Musique du menu : déposez ici un fichier MP3 nommé  music-menu.mp3  (il sera joué en boucle dans les menus).
Sans ce fichier, le jeu joue un groove house synthétisé à la place. Les courses jouent une musique chill synthétisée.
Après l'ajout : npm run sw  (pour que le jeu hors ligne le garde en cache).
