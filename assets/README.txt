Musique des courses : déposez ici un fichier MP3 nommé  music-game.mp3  (il sera joué en boucle pendant les courses).
Sans ce fichier, le jeu joue une musique chill synthétisée à la place. Le menu garde sa musique synthétisée.
Après l'ajout : npm run sw  (pour que le jeu hors ligne le garde en cache).
